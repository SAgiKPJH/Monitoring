# 알람 규칙 (15_rdk_x5_runtime)

`monitoring.py` 가 위험 상태를 감지해 `src/alarm.py` 로 알람을 보낼 때의 규칙.

## 언제 보내나 (트리거)

baby(또는 baby_face)가 감지되면 **30초 관찰 창**(`OBS_SEC=30`, `POLL_SEC=2` → 15회 폴)을 돌리고,
폴의 **`OBS_RATIO=0.5`(절반) 이상**에서 관찰된 조건만 발신. 폴 몇 번 놓쳐도 취소되지 않는다("30초 내내 지속" 아님).

| 알람 key | 조건 (30초 관찰 창 안에서) | 임계 |
|---|---|---|
| `face:eyes_open` | baby_face 크롭에서 **눈 뜸**(깨어 있음) 관찰 | `ATTR_THR` eyes_open 0.9 |
| `face:mouth_covered` | **입 가려짐**(이불 등) 관찰 | mouth_covered 0.7 |
| `face:frown` | **인상**(울기 직전) 관찰 | frown 0.8 |
| `pose` | pose keypoint **이동량**이 `POSE_MOVE_THR` 초과(움직임) 관찰 | POSE_MOVE_THR=0.022 |

- 얼굴 3개 속성은 **한 번의 30초 창**에서 같이 관찰하고 속성별로 따로 발신(`FACE_ALARM_ATTRS`).
- baby/baby_face 감지 자체 임계: `BABY_CONF=0.8` · `FACE_CONF=0.8`.
- 남은 폴을 전부 맞혀도 비율에 못 미치면 창을 조기 종료하고 다음 단계로.

## 반복 방지 (쿨다운)

- **동일 알람(key)은 5분에 한 번만** — `ALARM_COOLDOWN=300`초. 쿨다운 내 같은 key 는 무시.
- key 가 속성별(`face:eyes_open` / `face:mouth_covered` / `face:frown` / `pose`)이라 눈 뜸 알람이 나간 뒤에도 입 가려짐 알람은 바로 나간다.

## 무엇을 보내나

- **텍스트** = 알람 내용 + **시각 id** `[YYYYmmdd_HHMMSS]` — 예: `눈 뜸(깨어 있음) — 30초 관찰  [20260906_143352]`.
  스냅샷은 `alarms/alarm_<시각 id>.jpg` 로 **로컬 저장**만 하고 **경로는 보내지 않는다**(id 로 파일을 찾음).
- **Slack**: `SLACK_WEBHOOK`(Incoming Webhook) 텍스트 전송(파일 첨부 불가).
- **Grafana**: `GRAFANA_URL`+`GRAFANA_TOKEN` 있으면 `/api/annotations` 텍스트 주석(태그 `baby-monitor`, `face`/`pose`, 속성명).
- 채널 미설정 시 **콘솔 출력만**(콘솔에는 저장 경로도 표시).

## 설정 (.env)

`cp .env_sample .env` 후: `SLACK_WEBHOOK`, `GRAFANA_URL`·`GRAFANA_TOKEN`, `ALARM_COOLDOWN`(초).
관찰 창·비율·트리거 속성은 `monitoring.py` 상단(`OBS_SEC`·`OBS_RATIO`·`FACE_ALARM_ATTRS`), 얼굴 속성 임계는 `src/face_thr.py`.
