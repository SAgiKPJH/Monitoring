# 알람 규칙 (15_rdk_x5_runtime)

`monitoring.py` 가 위험 상태를 감지해 `src/alarm.py` 로 알람을 보낼 때의 규칙.

## 언제 보내나 (트리거)

baby(또는 baby_face)가 감지되면 **30초 관찰 창 1개**(`OBS_SEC=30`, `POLL_SEC=2` → 15회 폴)를 돌린다.
폴마다 프레임 1장으로 **얼굴 속성과 pose 움직임을 같이** 확인하고, 폴의 **`OBS_RATIO=0.5`(절반) 이상**에서 관찰된 조건을 발신.
폴 몇 번 놓쳐도 취소되지 않는다("30초 내내 지속" 아님).

| 조건 key | 조건 (30초 관찰 창 안에서) | 임계 |
|---|---|---|
| `face:mouth_covered` | baby_face 크롭에서 **입 가려짐**(이불 등) 관찰 | `ATTR_THR` mouth_covered 0.7 |
| `face:frown` | **인상**(울기 직전) 관찰 | frown 0.8 |
| `face:eyes_open` | **눈 뜸**(깨어 있음) 관찰 | eyes_open 0.9 |
| `pose` | pose keypoint **이동량**이 `POSE_MOVE_THR` 초과(움직임) 관찰 | POSE_MOVE_THR=0.022 |

- baby/baby_face 감지 자체 임계: `BABY_CONF=0.8` · `FACE_CONF=0.8`. 얼굴은 창 안에서 폴마다 다시 감지한다(감지 순간에 얼굴이 없어도 됨).
- 남은 폴을 전부 맞혀도 어떤 조건도 비율에 못 미치면 창을 조기 종료하고 다음 사이클로.

## 무엇을 보내나 — 관찰된 조건을 한 문구로

- 같은 창에서 관찰된 조건을 **` + ` 로 이어 1건**으로 보낸다(위 표 순서). 뒤에 **시각 id** `[YYYYmmdd_HHMMSS]`.
  - 예: `눈 뜸(깨어 있음) + pose 변화(자주 움직임) — 30초 관찰  [20260906_204147]`
  - 예: `pose 변화(자주 움직임) — 30초 관찰  [20260906_204147]` (pose 만 관찰)
- 스냅샷은 `alarms/alarm_<시각 id>.jpg` 로 **로컬 저장**만 하고 **경로는 보내지 않는다**(id 로 파일을 찾음).
- **Slack**: `SLACK_WEBHOOK`(Incoming Webhook) 텍스트 전송(파일 첨부 불가).
- **Grafana**: `GRAFANA_URL`+`GRAFANA_TOKEN` 있으면 `/api/annotations` 텍스트 주석(태그 `baby-monitor` + 관찰된 조건명).
- 채널 미설정 시 **콘솔 출력만**(콘솔에는 저장 경로도 표시).

## 반복 방지 (쿨다운) — 조건별

- **같은 조건 key 는 5분에 한 번만** — `ALARM_COOLDOWN=300`초.
- 쿨다운은 문구 단위가 아니라 **조건별**: 쿨다운 안인 조건은 문구에서 빠지고 나머지만 나간다.
  - 예: `눈 뜸 + pose` 발신 3분 뒤 같은 창에서 `입 가려짐 + pose` 관찰 → `입 가려짐(이불 등) — 30초 관찰` 만 발신(pose 는 쿨다운).
  - 관찰된 조건이 전부 쿨다운 안이면 발신하지 않는다.

## 설정 (.env)

`cp .env_sample .env` 후: `SLACK_WEBHOOK`, `GRAFANA_URL`·`GRAFANA_TOKEN`, `ALARM_COOLDOWN`(초).
관찰 창·비율·트리거 속성은 `monitoring.py` 상단(`OBS_SEC`·`OBS_RATIO`·`FACE_ALARM_ATTRS`·`ATTR_LABEL` 문구), 얼굴 속성 임계는 `src/face_thr.py`.
