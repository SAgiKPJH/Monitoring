## C1 어른손 — 상세 (2026-07-30 눈검증 완료) ✅

검증 시트: `verify_C1_adult.png`(양성 상위 8클립×4프레임) / `verify_C1_babyhand.png`(손 검출됐지만 음성 8클립).

- **양성(pred=1) 정밀도 높음**: 상위 8건 중 7~8건이 실제 어른 손/팔 — 장난감 든 손(주간 컬러),
  기저귀 갈이 팔, 카메라 조작 손, 근접 팔뚝 등. MediaPipe Hands + 크기비율 휴리스틱이 유효.
- **음성 분기("아기손" 판정)는 신뢰 불가 (사용자 지상검증)**: pred=0 인데 손이 검출된
  사례들은 실제 아기 손을 제대로 잡은 게 아님 — 원거리 어른 손 미탐 포함, "작은 손 검출
  = 아기 손"이라는 가정이 성립하지 않음.
- **함의**: C1 은 **양성 전용 감지기**(어른 개입 있음)로만 사용. `hand_frames` 를
  **D4(아기 손 나옴)의 신호로 재사용하지 말 것** — D4 는 포즈 손목(06_pose)도 실패했므로
  현재 무라벨 경로가 없음 → HD 재시도 또는 직접 구축 후보.
- 시간대 균일(새벽 12%)은 이상 아님 — 밤중 수유·돌봄 + 클립 자체가 움직임 순간만 존재.
- **개선(C1 v2)**: 크기비율 단독 → Grounding DINO "adult hand" 제로샷 또는 대형 전경
  움직임 결합으로 원거리 손 재현율 보강. (억제 용도론 현재 정밀도만으로도 사용 가능)
