# notebooks_original — 원본(HD) 영상 기반 모델 확보

## 전략

240×136 에서 시각 모델들이 궤멸(1차 결과: `result/Result.md`)했으므로 순서를 뒤집는다:

1. **1단계 (이 폴더)**: Cut 원본(1920×1080)에서 **되는 모델부터 확보** — 검출률·정밀도가
   HD 에서 확인되면 방법 자체는 확정.
2. **2단계 (추후)**: HD 에서 되는 모델을 **작은 이미지(240p)로 이식** — 경로 후보:
   (a) HD 모델을 교사로 저해상도 학생 증류, (b) 저해상도 파인튜닝(same-architecture),
   (c) 입력단 초해상(SR) 전처리, (d) RDK X5 에서 원본 스트림 크롭을 직접 사용(이식 불필요).

## 구성 (전부 시각 계열 — 오디오 3종은 해상도 무관이라 제외)

| 노트북 | 라벨 | Colab 자원 | 240p 1차 결과 | HD 에서 확인할 것 |
|---|---|---|---|---|
| `06_pose` | D2 움직임·D4 손 | **T4** (onnxruntime-gpu) | 검출률 4.7% | 인물 검출률 회복 여부 (오버레이 확인) |
| `D3_eyes_open` | 눈뜸 | **CPU 가능** (MediaPipe, GPU 미사용) | EAR 변별력 없음 | 눈 랜드마크 정밀도 회복 여부 |
| `C1_adult_hand` | 어른손 | **CPU 가능** (MediaPipe, GPU 미사용) | ✅ 양성 정밀 | 원거리 손 재현율 개선 |
| `C2_baby_absent` | 아기 유무 | **T4 필요** (Grounding DINO) | 불확실 68% | 이불 속 아기 검출 점수 상승 |
| `D1_nose_covered` | 코가림 | **T4 권장** (CLIP은 GPU, FaceMesh는 CPU) | 신뢰 불가 | face_frac 살아나면 앙상블 재계산 |
| `D9_mouthing` | 뻐끔 | **CPU 가능** (FaceMesh+광학흐름, GPU 미사용) | MAR 죽음 | MAR 경로 부활 여부 |
| `D5_pre_cry` | 울기직전 | **T4 필요** (AST·CLIP) | 앵커 부실 | 얼굴 신호 회복 (오디오 문제는 별도) |
| `D6_spit_up` | 토 | **T4 필요** (OWL-ViT·AST) | 양성 2건 | 입 주변 신호 정밀화 |

- GPU 미사용(CPU 가능) 노트북이라도 HD 라 처리량이 커져 240p 대비 클립당 수 배 느려짐 —
  CPU 세션에서 돌리되 N_CLIPS 를 300 정도로 시작 권장.
- T4 계열은 전부 무료 T4 1개로 충분 (A100 불필요).

- 결과는 `auto_<라벨>_hd.csv` / `pose_results_hd.csv` 로 저장 — 240p 결과와 직접 비교 가능.
- 업스케일은 1배로 변경(원본이 이미 큼). HD 라 클립당 처리 시간이 늘어남 — N_CLIPS 를
  낮춰 시작(예: 300)해도 됨.
- 실행 우선순위: **06_pose → D3 → C2** (병목 해소 여부가 가장 빨리 판가름) → 나머지.
