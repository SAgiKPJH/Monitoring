# 라벨링 툴 명세 (Labeling Tool Spec)

> 본 문서는 **요구사항·설계 명세**입니다. 코드 구현은 추후. 현행 `label_tool`(2클래스 하드코딩)
> 을 **설정 기반 N클래스 + 매크로**로 확장하는 것을 목표로 합니다.

## 1. 배경 / 목적

- **현재**: `main.py`(모드 A 이미지편집 / B 클립추출), 클래스(baby=0, baby_face=1)·색·단축키(`1`/`2`)가
  코드(`labeler_view.CLASS_NAMES/CLASS_COLORS`, `*_ui._handle_key`)에 **하드코딩**.
- **문제**: 클래스가 바뀌거나(예: baby_face → hand, blanket) 프로젝트가 달라질 때마다 코드를 고쳐야 함.
  또 같은 구도의 반복 라벨링(고정 카메라)이 손이 많이 감.
- **목표**:
  1. 클래스 정보(이름·색·단축키)를 **YAML 설정**으로 외부화하고 `--config` 로 지정 → 코드 수정 없이 클래스 교체.
  2. 라벨링 동작을 **매크로로 녹화·재생**(+단축키 할당) → 반복 작업 가속.

## 2. 범위

- **대상**: `8_detection_2class_train\label_tool` (모드 A/B 공통).
- **포함**: (F1) 클래스 설정 YAML, (F2) 매크로 녹화/재생 및 관련 설정.
- **유지(불변)**: YOLO 라벨 포맷(`<cls> cx cy bw bh`), dataset 제자리 편집/추출, 네거티브(빈 라벨),
  증분 저장, BGR 무변환, Training_Standard 규격(파일 ≤150/≤200줄).
- **제외**: 학습·추론 로직, 자동 라벨(그건 `7_auto_labeling`).

## 3. 핵심 요구사항

### F1. 클래스 설정 YAML

| # | 요구 | 상세 |
|---|---|---|
| F1-1 | 클래스 외부 정의 | 각 클래스의 `id·name·color(BGR)·key(단축키)` 를 YAML 로 정의 |
| F1-2 | 파라미터 지정 | 실행 시 `--config <경로.yml>` 로 설정 파일 지정 (미지정 시 내장 2클래스 폴백) |
| F1-3 | N클래스 일반화 | 2개 하드코딩 제거 → YAML 항목 수만큼 클래스 지원 |
| F1-4 | classes.txt 동기화 | YAML 클래스 순서(id 오름차순)로 `dataset\classes.txt` 생성/갱신 → 학습 nc 일치 |
| F1-5 | 활성 클래스 전환 | YAML 의 `key` 로 활성 클래스 전환, 오버레이에 이름·색 표시 |
| F1-6 | 검증 | id 0..N-1 연속·유일, key 1글자·예약키 미충돌, color 0~255 3요소 — 위반 시 로드 실패(명확한 메시지) |

- **효과**: `labeler_view.CLASS_NAMES/CLASS_COLORS`, `_handle_key` 의 `1`/`2` 분기가 설정 주도로 대체됨.
- **색 표기**: 기본 BGR 배열. 편의를 위해 `"#RRGGBB"`(HEX) 도 허용해 내부에서 BGR 변환 (결정 필요, §8).

### F2. 매크로 녹화 / 재생

| # | 요구 | 상세 |
|---|---|---|
| F2-1 | 녹화 | 토글 키로 녹화 시작/종료. 그 사이의 **키·마우스 박스** 동작을 순서대로 기록 |
| F2-2 | 단축키 할당 | 녹화한 매크로에 **이름 + 재생 단축키** 지정 |
| F2-3 | 재생 | 할당 키를 누르면 기록된 액션 시퀀스를 현재 프레임/이미지에 그대로 재생 |
| F2-4 | 영속화 | 매크로를 파일(`macros.yml`)로 저장·로드 (세션 간 유지) |
| F2-5 | 해상도 독립 | 박스 좌표는 **정규화(0~1)** 로 저장 → 이미지 크기가 달라도 재생 가능 |
| F2-6 | 관리 | 매크로 목록 보기·삭제. 녹화 토글 키·기본 저장 위치는 설정으로 |

- **용도 예**: 고정 카메라라 아기 위치가 대개 비슷 → "침대 영역에 baby 박스 + 얼굴 박스 + 저장 + 다음"
  을 한 키로. 또는 "현재 프레임을 네거티브로 저장 + 다음" 반복.
- **기록 대상 액션**: 클래스 전환(id), 박스 추가(정규화 x1,y1,x2,y2,cls), `u`/`c`, 저장(`space`/`x`),
  이동(`n`/`p`/`a`/`d`/`w`/`s`). (마우스 이동 자체는 제외, **결과 박스**만 기록)
- **주의**: 재생 중 사용자 개입(중단), 프레임 없음/클립 경계, 저장 실패 시 중단 — §8.

### F3. 박스 선택 · 수정 · 개별 삭제

현재는 박스 추가(드래그)와 `u`(마지막 취소)·`c`(전체 삭제)만 가능. 이미 그린 박스를 **골라서**
고치거나 하나만 지우는 편집을 추가한다.

| # | 요구 | 상세 |
|---|---|---|
| F3-1 | 박스 선택 | 기존 박스를 **클릭해 선택**(활성 박스). 선택 박스는 강조(두꺼운 테두리 + 모서리 핸들) |
| F3-2 | 사각형 수정 | 선택 박스의 **크기**(모서리·변 핸들 드래그) 와 **위치**(내부 드래그 이동) 수정. 원본 픽셀 기준 |
| F3-3 | 클래스(라벨) 변경 | 박스 선택 상태에서 클래스 단축키를 누르면 **그 박스의 클래스**를 재지정 (라벨 정보 선택 후 수정) |
| F3-4 | 개별 삭제 | 선택한 박스 **하나만** 삭제(`Delete`/`Backspace`). `u`(마지막)·`c`(전체)와 별개 |
| F3-5 | 선택 해제 | 빈 곳 클릭 또는 지정 키로 해제 |

- **마우스 상호작용 규칙(초안)**: 빈 영역 드래그 = **새 박스**(활성 클래스) · 기존 박스 클릭 = **선택** ·
  핸들 드래그 = **리사이즈** · 박스 내부 드래그 = **이동**. (판별 임계·핸들 크기는 §8)
- 편집 결과도 정규화(F2-5) 저장 규격과 일관되게 유지.

### F4. 화면 표시 (HUD 패널)

라벨 정보를 화면에 **색·이름**과 함께 보여주고, 현재 프레임의 박스 목록도 표시한다.

| # | 요구 | 상세 |
|---|---|---|
| F4-1 | 클래스 범례 | 각 클래스를 **[색 스와치] 이름 (단축키)** 형태로 나열. 활성 클래스 강조 |
| F4-2 | 현재 박스 목록 | 범례 **아래**에, 현재 프레임의 박스를 나열: `#인덱스 · 클래스명(색) · 위치/크기`. 선택 박스 강조 |
| F4-3 | 카운트 | 클래스별 박스 개수 요약(예: baby 2 · baby_face 1) |
| F4-4 | 배치 | 좌상단 패널(기존 상태줄 확장). 이미지 가림 최소화(반투명/외곽), 토글 키로 숨김 가능 |

- 범례 색·이름은 **F1 의 YAML** 정의를 그대로 사용(단일 출처).
- 박스 목록은 F3 선택/삭제와 연동(목록에서 어떤 박스가 선택됐는지 보임).

### F5. 랜덤 이동 이력 (이전 랜덤으로 되돌아가기)

`r`(랜덤 점프)로 이동하면 어디를 봤는지 놓치기 쉽다. **방문한 랜덤 대상을 이력으로 쌓고
되돌아갈 수** 있게 한다.

| # | 요구 | 상세 |
|---|---|---|
| F5-1 | 랜덤 이력 기록 | `r` 로 랜덤 이동할 때 방문 대상(이미지/클립 인덱스)을 이력 스택에 push |
| F5-2 | 이전 랜덤 복귀 | 지정 키로 **직전 랜덤 위치로 되돌아가기**(스택 pop). 반복 시 더 이전으로 |
| F5-3 | 앞으로 (선택) | 되돌린 뒤 다시 앞 랜덤으로 이동 (지원 여부 §8) |

- `p`(순차 이전)와 **의미가 다름**: `p` 는 목록상 바로 앞, 이것은 **랜덤 방문 순서**의 이전.
- 예약 여유 키 1개 배정. 이력 깊이(무제한 vs N)는 §8.

## 4. 설정 파일 스키마 (초안)

### 4.1 클래스 설정 `label_config.yml`

```yaml
# --config 로 지정. 클래스 순서(id) = dataset\classes.txt 줄 순서.
dataset:
  images: ..\..\7_auto_labeling\dataset\images   # 모드 A 기본 편집 대상 (선택)
  out:    ..\..\7_auto_labeling\dataset          # 모드 B 추출 저장 위치 (선택)
classes:
  - { id: 0, name: baby,      color: [0, 255, 0],   key: "1" }   # color = BGR
  - { id: 1, name: baby_face, color: [255, 0, 255], key: "2" }
```

- `dataset.images/out` 은 CLI(`--images`/`--out`)가 우선, 없으면 이 값 사용.
- 이 YAML 로 `classes.txt` 를 자동 생성(있으면 갱신)한다.

### 4.2 매크로 파일 `macros.yml`

```yaml
record_toggle_key: "`"        # 녹화 시작/종료 토글 (예약키와 미충돌)
macros:
  - name: bed_baby_and_face
    key: "z"                  # 재생 단축키
    actions:
      - { type: class, id: 0 }
      - { type: box, cls: 0, rect: [0.30, 0.35, 0.72, 0.95] }   # 정규화 x1,y1,x2,y2
      - { type: box, cls: 1, rect: [0.44, 0.40, 0.56, 0.52] }
      - { type: save }        # positive 저장
      - { type: next }        # 다음 이미지/클립
```

## 5. 단축키 체계

- **예약(고정) 키** — 사용자·매크로가 재정의 불가:
  `n p r a d w s u c x q`, `SPACE(32)` `ENTER(13)` `ESC(27)`, `DELETE`/`BACKSPACE`(개별 삭제), 트랙바.
- **사용자 지정 키**:
  - 클래스 선택: `classes[].key` (기본 `1` `2` …) — 박스 선택 상태면 그 박스 클래스 변경(F3-3)
  - 매크로 재생: `macros[].key`
  - 녹화 토글: `record_toggle_key`
  - HUD 토글(F4-4): 예약 여유 키 1개
  - 이전 랜덤 복귀(F5-2): 예약 여유 키 1개
- **마우스**: 빈영역 드래그=새박스 · 박스클릭=선택 · 핸들드래그=리사이즈 · 내부드래그=이동 (F3).
- **충돌 규칙**: 사용자 지정 키가 예약키 또는 서로 겹치면 **로드 시 에러**. 권장 여유 키:
  숫자 `1`~`0`, 문자 `e f g h i j k l m o t v y b` 등.

## 6. 기존 기능 (유지·불변 — 확장 후에도 회귀 금지)

아래는 **현행 `label_tool` 실동작 전수 목록**이다. F1~F5 확장 후에도 모두 유지되어야 한다.

### 6.1 모드 · 입출력
- **모드 A(이미지 편집, `--images`)**: 폴더의 이미지를 열어 **라벨 txt 만** 갱신(이미지 파일 불변).
  라벨 저장 위치 `--labels`(기본: images 형제 `labels\`).
- **모드 B(클립 추출, `--clips`)**: mp4에서 고른 프레임을 **JPEG+라벨로 추출** 저장(`--out` dataset,
  파일명 `<클립>_f####`). `--clips` 는 **복수 폴더/파일**(경로 중복 제거·이름순 정렬).
- 기본 경로: images=`..\..\7_auto_labeling\dataset\images`, out=`..\..\7_auto_labeling\dataset`.
- 이미지 확장자 jpg/jpeg/png/bmp, JPEG 품질 95. cv2/numpy 미설치 시 친절한 안내 후 종료.
- `--images` 는 폴더 또는 **단일 이미지 파일**도 허용(모드 B `--clips` 도 파일 1개 가능).
- 소스에 대상이 없으면 종료(exit 1, `no image/mp4 found`). `--clips` 복수 중 빈 소스는
  `[warn] no mp4 at: <src>` 만 찍고 계속.

### 6.2 탐색 (내비게이션)
- 공통: `n` 다음 · `p` 이전 · `r` 랜덤(현재와 다른 대상).
- 모드 B 전용: `a`/`d` ±1프레임 · `w`/`s` ±1초(fps 기반, fps 불명·0이면 **15fps 폴백**) · **트랙바** 프레임 탐색.
- 읽을 수 없는 이미지/클립은 **건너뛰고**, 이미지/클립 **목록**은 끝에서 **순환(wrap)**.
- 반면 **클립 내부 프레임 이동/트랙바는 `[0, N-1]` 로 클램프(순환 없음)**; 프레임 읽기 실패 시
  현재 프레임 유지 + `cannot read frame N` 플래시.

### 6.3 박스 · 클래스 · 저장
- 활성 클래스 전환(현행 `1`/`2`) — **F1 로 일반화**.
- 드래그로 박스 추가, `u` 마지막 취소, `c` 전체 비우기, 너무 작은 드래그(<MIN_BOX_PX)는 무시.
- 드래그 좌표는 이미지 경계 `[0,w-1]/[0,h-1]` 로 **클램프**(가장자리를 넘겨도 안쪽 박스로).
- `SPACE`/`ENTER` positive 저장 · `x` 네거티브(빈 라벨; 박스 있으면 `c` 후) 저장.
- YOLO 포맷 `<cls> cx cy bw bh`(정규화, 클래스 id 포함).

### 6.4 상태 · 표시
- 프레임 열 때 **저장된 라벨 자동 로드**(재편집).
- 상단 **헤드라인**: `[i/N IMG|CLIP] 파일명` + (클립) `f현재/총프레임`.
- 저장 상태 태그(SAVED POSITIVE/NEGATIVE) 및 pos/neg·총계 표시 — **F4 로 확장**.
- 하단에 **단축키 도움말 줄** 상시 표시.
- 큰 프레임은 화면(≤1600×900)에 맞춰 축소 표시(저장은 **원본 해상도**).
- 박스는 클래스 색으로 그리고 이름을 박스 위에 표기, 드래그 중 미리보기(노랑), 저장 시 플래시 메시지.

### 6.5 규격 · 견고성
- BGR 무변환(Training_Standard). unicode 경로 안전(`np.fromfile`/`imencode().tofile`).
- 증분: 이미 저장된 것은 유지·재편집(중단 후 재실행 안전).
- 대문자 키 허용: Shift/CapsLock 으로 들어온 A–Z 는 소문자로 취급.
- 라벨 로드 시 형식 불량 줄(필드 5개 아님·비숫자)은 조용히 건너뜀.
- 디코드 가능한 소스가 하나도 없으면 `[ERROR] no readable ...` 후 종료(exit 1).
- 종료: `q`/`ESC` 또는 창 닫기.

## 7. 비기능 요구

- Training_Standard: 파일당 ≤150줄(하드 ≤200), BGR 무변환, config-at-top/얇은 진입점.
- 실행: Windows + venv(`..\..\.venv`). 신규 의존성 **pyyaml** 필요.
- 하위호환: `--config` 미지정 시 현행 2클래스 동작 그대로.

1. **색 표기**: BGR 배열만 vs HEX(`#RRGGBB`)도 허용?
2. **classes.txt 권위**: YAML→classes.txt 단방향 생성 vs 기존 classes.txt 있으면 존중?
3. **매크로 저장 위치**: label_tool 폴더 vs dataset 옆 vs `--macros` 로 지정?
4. **매크로 좌표계**: 정규화(권장) 확정? letterbox/원본 중 기준 프레임?
5. **재생 중 개입**: 재생을 중간에 멈추는 키(ESC)로 통일?
6. **YAML 로 모드까지 지정**? (A/B, 기본 소스) — 아니면 CLI 유지?
7. **선택 해제 vs 종료(ESC)**: 박스 선택 있으면 해제, 없으면 종료 — 이렇게 이중 동작?
8. **마우스 판별 임계**: 새박스/선택/이동 구분 기준(클릭 이동 픽셀 임계·핸들 크기)?
9. **랜덤 이력**: 깊이 무제한 vs N개, "앞으로(F5-3)" 지원 여부?

## 9. 단계 (Roadmap)

- **P1 — 클래스 YAML(F1) + HUD(F4)**: `--config` 로드, view/ui 설정 주도, classes.txt 동기화·검증,
  범례(색+이름)·현재 박스 목록 표시.
- **P2 — 박스 편집(F3) + 랜덤 이력(F5)**: 선택·리사이즈·이동·클래스 변경·개별 삭제, 랜덤 되돌리기.
- **P3 — 매크로(F2)**: 녹화 토글·박스/키 기록(정규화)·`macros.yml` 영속화·재생.
- **P4 — 관리 편의**: 매크로 목록/삭제 UI, 설정 오류 친절 메시지, config 예시 동봉.

## 10. 완료 기준 (Acceptance, 요약)

- `--config baby2.yml` 로 실행 시 코드 수정 없이 클래스/색/단축키가 바뀌고 `classes.txt` 가 일치한다.
- 화면에 클래스 범례(색+이름·단축키)와 현재 프레임 박스 목록이 표시되고, 선택 박스가 강조된다.
- 기존 박스를 클릭 선택해 **리사이즈·이동·클래스 변경·개별 삭제**할 수 있다.
- `r` 랜덤 이동 후 **이전 랜덤 위치로 되돌아갈** 수 있다.
- 매크로를 녹화→키 할당→재생하면 동일 액션이 재현되고, 다른 해상도 이미지에서도 박스가 올바른 위치에 찍힌다.
- 잘못된 config(키 충돌·id 불연속)는 실행 초기에 명확한 에러로 걸린다.
