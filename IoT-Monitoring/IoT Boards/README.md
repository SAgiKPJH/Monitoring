# 1. D-Robotics RDK X5 (로봇/자율주행 특화)## 🔍 중고 수령 후 정상 동작 확인법

* 전원 공급: 반드시 5V/3A ~ 5V/5A 고출력 어댑터와 정품 Type-C 케이블을 사용하세요. (PC USB 연결 시 무한 재부팅 발생).
* LED 상태 확인:
1. 전원 연결 시 초록색 전원 LED 점등 확인.
   2. 시스템 가동 시 주황색 상태(Status) LED가 깜빡이는지 확인.
* 화면 출력 (OS 부팅):
* HDMI 케이블 연결 후 50~80초 이내에 Ubuntu 데스크톱 화면이 모니터에 출력되는지 확인.
* 원격 접속 테스트 (화면 미출력 시):
* 랜선 연결 후 기본 IP 192.168.1.10으로 ping 테스트 또는 SSH(Putty 등) 접속 시도. (기본 계정/비번: sunrise / sunrise).

## 💡 개발 목적 및 활용도

* 핵심 목적: 로봇 운영체제(ROS 2) 하드웨어 가속 및 온디바이스(On-device) 엣지 AI 비전 컴퓨팅 개발.
* 주요 활용:
* 자율주행 모바일 로봇(AGV/AMR)의 SLAM 및 경로 탐색 두뇌.
   * 4족 보행 로봇 및 자율비행 드론 제어.
   * 실시간 AI 객체 인식/추적 스마트 카메라 시스템 구축.

## OS

* D-Robotics RDK X5 공식 OS 수동 설치
  * [메뉴얼](https://d-robotics.github.io/rdk_doc_center/en/)
  * [OS 이미지](https://archive.d-robotics.cc/downloads/os_images/rdk_x5/)
  * [SD카드 Rufus](https://rufus.ie/en/)


## 💾 저장장치 특성 및 SD 카드 추천

* 특성: 내장 메모리(eMMC)가 없으므로 반드시 OS가 탑재된 마이크로 SD 카드가 필수입니다. 슬롯이 비어있으면 켜지지 않습니다.
* 추천 용량: 64GB 이상 (Ubuntu + ROS 2 기본 환경 구축 및 AI 데이터셋 저장용).

# 2. Khadas VIM3 Basic (인공지능/미디어 특화)## 🔍 중고 수령 후 정상 동작 확인법

* 전원 공급: 고출력 PD 충전기 사용 권장.
* LED 상태 확인:
* 파란색 LED (Solid ON): 전원 정상 공급 후 대기(꺼짐) 상태.
   * 하얀색 LED (Solid ON 또는 숨쉬기 깜빡임): 내부 OS 정상 구동 중인 상태.
   * ※ 하얀색 LED가 무한히 아주 빠르게 깜빡인다면 부팅 오류(Bootloop)일 수 있음.
* 화면 출력 (OS 부팅):
* 마이크로 SD 카드를 꽂지 않은 상태에서 HDMI 연결 후 Khadas 로고 및 내장 OS(안드로이드 또는 리눅스) 홈 화면 진입 확인.
* TST 모드 (하드웨어 테스트):
* 전원 인가 후 가운데 Function 버튼을 2초 내에 빠르게 3번 클릭 → 파란색 LED가 3초간 깜빡인 후 완전히 꺼지면 MCU(제어 칩셋) 정상 반응.

## 💡 개발 목적 및 활용도

* 핵심 목적: 고성능 5.0 TOPS NPU를 활용한 얼굴/객체 인식 AI 알고리즘 연산 및 멀티미디어 시스템 개발.
* 주요 활용:
* 안드로이드 TV 기반 셋톱박스 및 고성능 미디어 플레이어.
   * 디지털 광고판 및 무인 결제 키오스크 프로토타입.
   * 스마트 홈 IoT 게이트웨이 및 홈 오토메이션 중심 서버.

## 💾 저장장치 특성 및 SD 카드 추천

* 특성: 16GB 고속 내장 메모리(eMMC)가 기본 탑재되어 있어, SD 카드 없이도 즉시 부팅 및 검수가 가능합니다. (eMMC는 납땜형 내장 메모리로, 탈착식 SD 카드보다 속도가 빠르고 안정적입니다).
* 추천 용량: 32GB (내장 용량이 부족하여 외부 OS 멀티부팅을 하거나 추가 저장소로 쓸 때만 필요).

# 🛠️ 마이크로 SD 카드 구매 및 표기 요약## 1. 로봇 보드용 추천 규격 마크
로봇 개발 보드는 끊임없이 데이터를 읽고 쓰므로 아래 기호가 있는 '삼성전자 EVO Plus' 또는 '샌디스크 Ultra/Extreme' 제품을 권장합니다.

* [XC] : 64GB 이상의 대용량 규격
* [I] : UHS-I 고속 버스 인터페이스
* [U3] 또는 [V30] : 초당 최소 30MB 쓰기 속도 보장 (AI 비전 처리용)
* [A2] : 앱 성능 등급 2 (SD 카드에 운영체제를 깔아 쓸 때 필수적인 읽기/쓰기 속도 최적화 마크, RDK X5에 강력 추천)

## 2. 규격 판별 팁

* 두 보드 모두 MicroSD 슬롯을 사용하므로, 일반 규격 SD카드가 아닌 손톱 크기의 MicroSD 단품 또는 MicroSD + SD 어댑터 포함 패키지를 구매하셔야 합니다.
